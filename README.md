# AGNE — Agilidad para Negocios

Landing page SPA en Angular para AGNE.

## Desarrollo
```bash
npm install
npm start
```

## Producción
```bash
npm run build
```

## GitHub Pages
El workflow `.github/workflows/deploy.yml` compila y publica automáticamente al hacer push a `main` una vez que GitHub Pages esté configurado para usar **GitHub Actions** como fuente.

URL esperada: https://agne-peru.github.io/web/
