# Pendientes SEO que requieren intervención del propietario

Estado iniciado: 2026-10-21

## Pendientes

- [ ] Configurar y verificar Google Search Console para el sitio.
- [ ] Enviar `sitemap.xml` desde Search Console y revisar cobertura/indexación.
- [ ] Configurar Google Analytics o herramienta equivalente de medición.
- [ ] Evaluar compra de dominio propio para AGNE y migración SEO controlada.
- [ ] Configurar DNS del dominio cuando se compre.
- [ ] Revisar/optimizar Google Business Profile de AGNE si se crea o conecta.
- [ ] Incorporar casos de éxito reales con datos autorizados de clientes.
- [ ] Incorporar reseñas/testimonios reales; no generar reseñas ficticias.
- [ ] Incorporar fotos reales de instalaciones y clientes cuando estén disponibles.
- [ ] Conseguir menciones y enlaces reales desde sitios externos relevantes.

## Nota

No se deben inventar clientes, reseñas, cifras ni autoridad externa. Estos puntos se trabajarán progresivamente a medida que existan los accesos y materiales necesarios.
